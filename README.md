# Shoe Store Backend 🥿👟

This is the backend for a **Shoe Store Application**, built with **Spring Boot**. The application provides a robust API for managing users, products, carts, orders, and more. It integrates seamlessly with modern front-end applications and supports common e-commerce functionalities.

---

## Features 🚀

- **User Management**: Handles user authentication, registration, and role-based access.
- **Product Management**: CRUD operations for products, categories, and product attributes.
- **Shopping Cart**: Add/remove items from the cart and calculate totals.
- **Wishlist**: Save items for future purchases.
- **Orders**: Manage orders and payments.
- **Reviews**: Submit and manage product reviews.
- **Addresses**: Save and manage user shipping addresses.
- **Payment Integration**: Process payments via a payment provider.

## Tech Stack 💻

- **Backend Framework**: Spring Boot (Version 3.2.5)
- **Database**: MySQL (or any JPA-compliant DB)
- **Security**: Spring Security with JWT
- **Build Tool**: Maven
- **Testing**: JUnit 5
- **API Documentation**: Swagger/OpenAPI
- **Logging**: SLF4J with Logback
